## 🛠️ Showcase Features

- **Interactive Architecture Modals:** Inspect system workflows, safety guardrails, and agent state machines.
- **Client-Side Live Demonstrators:** Test simulated runs of multi-agent decomposition, SQL generation with mutation protection, email forensic header checks, and invoice reconciliation directly in the browser.
- **One-Click Links:** Jump directly to codebases, unit test suites (77/77 tests passing across the suite), and API documentation.
- **Fast, Responsive Design:** Built with Tailwind CSS, FontAwesome, zero heavy build tools, loaded securely over GitHub Pages CDN.

To preview the portfolio showcase locally:

```bash

python -m http.server 3000
# Open http://localhost:3000
```
